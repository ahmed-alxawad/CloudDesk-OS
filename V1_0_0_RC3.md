# CloudDesk-OS v1.0.0-rc.3

## Release Candidate 3

This release candidate includes the final fixes from the engineering closure phase to achieve 100% completion across all domains, and specifically resolves the test failures observed in `v1.0.0-rc.2`.

### Changes

- **S3 Virtual Hosted-Style Addressing**: Fixed an issue where the MinIO test failed due to `aws_sdk_s3` using virtual hosted-style addressing. `force_path_style(true)` is now explicitly configured for the S3 VFS provider, allowing it to work with local MinIO instances properly.
- **SSH/SFTP Client Bounds**: Fixed `russh` trait mismatches and resolved compilation errors inside the `remote` crate. Removed unused lifetimes and properly implemented the required async methods.
- **Live Acceptance Tests**: A full, unmocked docker-compose test matrix was successfully executed against live OpenSSH, WebDAV, and MinIO instances. The acceptance tests report conclusively demonstrates that the application works end-to-end.
